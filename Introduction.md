# An Introduction

I've been working on this plugin, designed to make it easy to visualise SBML files (systems biology files) using the obsidian application. I know the combination sounds a bit weird, but I'm basically just making use of the native obsidian graph view and nice markdown viewer.

This plugin exists currently as an obsidian plugin for the highest ease of use. I figured, for non-technical users, downloading an application and enabling a plugin was the lowest friction way I could get this working with low effort. I don't need the plugin to do anything fancy, I just want it to do this one thing and do it well. We're not trying to make some overhyped narrative with what it will do, we're simply trying to allow scientists and researchers to understand systems biology models more.

Please take a good look at all the existing code and let me know what you think. Be as critical as you want to be. A big blindspot I'm aware of is that I've only worked with particular kinds of models, so other models may not be well represented from the assumptions I've made. I also don't write TypeScript myself, though I can roughly read it and read JS a bit.

The other context for this is that I want to get it release on github soon, but not at the cost of it working robustly. This needs to work well, or else it's not worth it. I have about 4-8 weeks to have this finished, at the maximum. So the next steps for me are to establish what are all the things to do next, and also to establish what my personal MVP specifications look like. The approach will then be to get it to that MVP stage as soon as I can, then iteratively work on subsequent versions afterwards.

Please feel free to ask me as many questions as you like, either via the interactive options I get, or as a questionnaire of questions in a separate document.
